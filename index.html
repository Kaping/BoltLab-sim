드래그 이동 · Shift+드래그 세로 이동 (구멍/축 자동 스냅)
R 회전 · F 세우기 · Q/E 높이 (Shift: 미세)
B 볼트 모드 → 링을 클릭해 체결 (노랑 = 고정 / 주황 = 회전):
 ● 볼트 판↔판 구멍 고정 (Shift+클릭: 회전볼트)
 ● 베어링 축을 판 구멍에 꽂기 — 위치만 잡고 축은 자유롭게 돎
 ● 클립 기어를 축에 끼워 고정 — 클립해야 기어가 축과 같이 돎
 ● 모터 모터 출력축에 기어/축 고정 — 모터가 이걸 돌림
 ● 체인 같은 평면의 체인기어 두 개를 체인으로 감기 — 같은 방향으로 잇수비만큼 돎
 ● 장공 장공에 볼트 — 미끄러지면서 돎 (볼트 2개 = 직선 피스톤)
 ● 고무줄 같은 평면의 풀리 두 개를 고무줄로 감기 — 같은 방향으로 지름비만큼 돎
체인/고무줄: 체인기어 또는 풀리 두 개를 Ctrl+클릭으로 선택 → C (또는 B 모드의 분홍/주황 링)
T 선택한 풀리에 타이어 씌우기/벗기기 (풀리 중·소·타이어풀리)
모터 쓰는 순서: ① 모터 받침판을 프레임에 볼트로 고정 ② 기어를 모터 축 쪽으로 끌어다 대면 방향·높이가 자동으로 맞춰짐 → B 에서 초록 링 ③ Space 재생
Space 재생/일시정지 · Esc 원위치 · G 바닥 고정 · [ ] 모터 속도
Ctrl+클릭 여러 개 선택 · Ctrl+G 그룹 고정 (Ctrl+Shift+G 해제)
Ctrl+C / V / X 복사·붙여넣기·잘라내기 · Ctrl+Z / Y 되돌리기·다시하기
