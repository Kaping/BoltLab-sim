# BoltLab-sim

½인치(12.7mm) 격자 금속 조립 키트 부품을 3D로 배치하고 M4 볼트로 체결하는 조립 시뮬레이터.

## 실행

```bash
# Docker (권장)
docker compose up --build
# → http://localhost:8080

# 또는 정적 서버 아무거나
python -m http.server 8080
npx serve .
```

빌드 단계 없음 — Three.js는 CDN importmap으로 로드 (인터넷 연결 필요).

## 조작법

| 입력 | 동작 |
|---|---|
| 팔레트 클릭 | 부품 추가 |
| 드래그 | 수평 이동 (구멍/축 자동 스냅) |
| Shift+드래그 | 세로(수직) 이동 |
| R / F | 90° 회전 (수평/수직) |
| Q / E | 높이 내림/올림 (Shift: 1mm 미세) |
| B | 볼트 모드 — 노랑=볼트, 하늘=클립(기어↔축), 보라=베어링(축↔판) |
| , / . | 선택한 축·기어 회전 구동 (기어 트레인에 감속비 반영 전파) |
| Del / X | 선택 부품 삭제 |
| 빈 곳 드래그 | 카메라 회전 (휠: 줌) |

체결된 부품은 하나의 어셈블리로 함께 움직입니다.
베어링은 위치만 구속(축은 자유 회전), 클립은 기어를 축에 고정(회전 전달)합니다.

## 설계 핵심

부품 규격을 사이트에서 파싱하지 않고 **12.7mm(½") 격자에서 파라메트릭 생성**:

- 구멍 피치 12.7mm, M4 구멍 Ø4.3, 강판 두께 1.2mm
- `스트립-N` 길이 = (N−1)×12.7 + 11  → 스트립-15 = 188.8mm ✓
- 기어 모듈 m = 50.8/76 ≈ 0.668: 평기어(소) 57T + 피니언 19T의
  축간거리가 정확히 25.4mm(구멍 2칸), 감속비 1:3 ✓
  (외경 검산: 평기어 39.4 ≈ 39.3mm, 피니언 14.0mm)

## 구조

```
index.html          UI 레이아웃 + importmap
src/generators.js   파라메트릭 지오메트리 (판/축/기어, 구멍 메타데이터)
src/catalog.js      6호 부품 카탈로그 (CSV 수량 반영)
src/assembly.js     부품 인스턴스 + 체결 그래프 (bolt/clip/bearing)
src/main.js         씬·팔레트·드래그/스냅/체결/회전 전달
data/parts_list.csv 부품리스트 CSV 원본
```
