# BoltLab-sim

½인치(12.7mm) 격자 금속 조립 키트 부품을 3D로 배치하고 M4 볼트로 체결하는 조립 시뮬레이터.

## 실행

```bash
# Docker (권장)
docker compose up --build
# → http://localhost:8080

# 또는 정적 서버 아무거나
python -m http.server 8080
npx serve .
```

빌드 단계 없음 — Three.js는 CDN importmap으로 로드 (인터넷 연결 필요).

## 조작법

| 입력 | 동작 |
|---|---|
| 팔레트 클릭 | 부품 추가 |
| 드래그 | 수평 이동 (구멍/축 자동 스냅) |
| Shift+드래그 | 세로(수직) 이동 |
| R / F | 90° 회전 (수평/수직) |
| Q / E | 높이 내림/올림 (Shift: 1mm 미세) |
| B | 볼트 모드 — 노랑=볼트, 하늘=클립(기어↔축), 보라=베어링(축↔판) |
| Shift+볼트 링 클릭 | 회전볼트 — 두 부품이 그 구멍을 축으로 돌 수 있게 체결 (링크 관절) |
| Space | 동작 시뮬 재생/일시정지 (시뮬 중엔 편집 잠금) |
| Esc | 시뮬 종료, 원위치 복귀 |
| G | 선택 부품의 덩어리를 바닥(고정)으로 지정 |
| [ / ] | 선택한 모터 속도 −/+10 rpm (패널 슬라이더도 가능) |
| , / . | 선택 부품을 손으로 돌리기 (시뮬 모드로 들어감) |
| Del / X | 선택 부품 삭제 |
| Ctrl+클릭 | 여러 부품 선택 추가/해제 (Ctrl+A 전체 선택) |
| Ctrl+G / Ctrl+Shift+G | 그룹 고정 / 해제 — 볼트 없이도 한 덩어리로 움직이고 시뮬에서도 강체 |
| Ctrl+C / V / X | 복사 / 붙여넣기(격자 2칸씩 비켜서) / 잘라내기 — 복사한 부품끼리의 체결·그룹도 같이 복사 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시하기 (최근 100단계) |
| 빈 곳 드래그 | 카메라 회전 (휠: 줌) |

체결된 부품은 하나의 어셈블리로 함께 움직입니다.
베어링은 위치만 구속(축은 자유 회전), 클립은 기어를 축에 고정(회전 전달)합니다.

## 동작 시뮬레이션

모터를 프레임에 볼트로 고정하고, 축을 모터 출력 허브에 꽂아 **모터 연결**(초록 링)하면 재생 시 그 축이 돕니다.

- **강체**: 볼트·클립으로 묶인 부품은 한 덩어리로 움직임
- **회전 관절**: 베어링(축↔판), 회전볼트(판↔판), 모터 연결(모터↔축)
- **기어**: 맞물린 기어쌍은 잇수비로 속도 구속 (유성기어처럼 받침이 도는 경우 포함)
- **링크**: 4절 링크·크랭크처럼 닫힌 고리도 풀이 (구속 솔버, `src/kinematics.js`)
- 못 움직이는 자세(비그라쇼프 링크의 한계, 기어비 모순 등)에 닿으면 **잠김**으로 멈추고 알려줌
- 바닥: 📌 고정한 부품 → 모터 몸체가 붙은 덩어리 → 관절이 가장 많은 덩어리 순으로 자동 선택
- 아직 없음: 중력·충돌(부품끼리 뚫고 지나감), 직교축 기어, 풀리·벨트

## 설계 핵심

부품 규격을 사이트에서 파싱하지 않고 **12.7mm(½") 격자에서 파라메트릭 생성**:

- 구멍 피치 12.7mm, M4 구멍 Ø4.3, 강판 두께 1.2mm
- `스트립-N` 길이 = (N−1)×12.7 + 11  → 스트립-15 = 188.8mm ✓
- 기어 모듈 m = 50.8/76 ≈ 0.668: 평기어(소) 57T + 피니언 19T의
  축간거리가 정확히 25.4mm(구멍 2칸), 감속비 1:3 ✓
  (외경 검산: 평기어 39.4 ≈ 39.3mm, 피니언 14.0mm)

## 구조

```
index.html          UI 레이아웃 + importmap
src/generators.js   파라메트릭 지오메트리 (판/축/기어, 구멍 메타데이터)
src/catalog.js      6호 부품 카탈로그 (CSV 수량 반영)
src/assembly.js     부품 인스턴스 + 체결 그래프 (bolt/pivot/clip/bearing/drive)
src/kinematics.js   동작 시뮬: 강체 묶기, 관절 트리, 폐루프·기어·모터 구속 LM 솔버
src/main.js         씬·팔레트·드래그/스냅/체결·시뮬 UI
data/parts_list.csv 부품리스트 CSV 원본
```
