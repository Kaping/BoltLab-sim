BoltLab 시뮬레이터로 돌아가기

이용약관

2026년 11월 5일 시행

1. 서비스

BoltLab-sim 은 브라우저에서 금속 구멍판 조립 키트 부품을 3D 로 맞춰 보고, 모터로 돌려 보는 무료 시뮬레이터예요. 계정 없이 쓸 수 있어요.

2. 사용 범위

  • 개인 학습, 설계 연습, 수업 자료 용도로 자유롭게 쓸 수 있어요
  • 서비스를 해킹하거나 과도한 요청으로 방해하는 행위는 할 수 없어요
  • 소스 코드의 이용 조건은 GitHub 저장소의 안내를 따라요

3. 내가 만든 구조물

조립한 구조물은 서버로 전송되지 않아요. 내보내기 코드나 파일로 직접 저장해야 하고, 저장하지 않은 작업은 페이지를 닫으면 사라져요. 구조물에 대한 권리는 만든 사람에게 있어요.

4. 수집하는 정보

이 서비스는 개인정보를 수집하지 않아요. 브라우저에는 도움말 열림 여부 하나만 저장돼요.

화면을 그리려고 외부 CDN(jsDelivr)에서 3D 라이브러리와 글꼴을 불러와요. 이때 접속 기록이 해당 CDN 에 남을 수 있어요.

5. 정확도

부품 치수와 움직임은 실물 규격을 참고해 계산한 근사값이에요. 실제 부품의 오차, 마찰, 강성은 반영하지 않아요. 시뮬레이션 결과를 실물 제작의 안전·성능 보증으로 쓰지 마세요.

6. 제휴와 상표

BoltLab-sim 은 특정 제조사나 판매사와 제휴·후원 관계가 없는 독립 프로젝트예요. 부품 이름과 규격에 언급되는 상표는 각 권리자의 것이에요.

7. 책임의 한계

서비스는 있는 그대로 제공돼요. 서비스 이용이나 중단, 오류로 생긴 손해에 대해 법이 허용하는 범위에서 책임지지 않아요.

8. 약관 변경

약관은 바뀔 수 있고, 바뀌면 이 페이지의 시행일을 갱신해요. 변경 뒤에도 계속 쓰면 새 약관에 동의한 것으로 봐요.

9. 문의

오류 제보와 문의는 GitHub 이슈로 남겨 주세요.
